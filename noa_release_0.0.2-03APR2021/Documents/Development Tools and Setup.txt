Configure Maven in VS Code :

a.       Goto File->Preferences->Settings

b.       Under Settings, Goto Extensions-> Maven for Java

c.       Under Maven > Executable: Path, enter 'mvn'

 

Run NOA Application :

a.       Open Project Folder in VS Code

b.       Wait for Maven to download plugins and provide options for build under 'MAVEN PROJECTS' Accordion

c.       Update DB host details in resources\applicaiton.properties

d.       Right-click on 'noa' and select Intall

e.       Click 'run' from the 'SPRING-BOOT DASHBOARD'

f.        Access application at 'http://localhost:8080'; Access REST interface at 'http://localhost:8080/api/'

g.       Login with as a user who has ADMIN role configured in DB for access to REST API work.
