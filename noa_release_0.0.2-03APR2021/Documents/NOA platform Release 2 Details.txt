Instructions for Build & Deployment :

DB Schema is changed. It is Mandatory to Update it (pgsql_noa_schema_030421.sql) & Default Data (pgsql_noa_default-data_030421.sql)
To Avoid Build Failure Doe to Failing Test Cases, Build the Application with : mvn "-DskipTests=true" "-Dskip.npm.test=true" install
Login as ‘admin:admin’ Default User for Full Access to Functionality
Access Service Endpoints
UI Console at http://localhost:8080

REST Endpoints @ http://localhost:8080/api

RESTCONF Operations @ http://localhost:8888/restconf/operations

Swagger Documentation @ http://localhost:8888/apidoc/explorer/index.html

Connect to Any NETCONF Device from UI Console : Network Elements > Element Inventory > Attach; And Explore the Device’s YANG Models in Swagger UI
YANG Models from the Device Get Downloaded to ‘Cache’ Directory
Generate Back-End JavaDocs with : mvn Javadoc:Javadoc
Generate Front-End Docs with : npm run doc
Run Backend & Front-End Tests with : mvn test
Run Back-End Only Tests with : mvn "-Dskip.npm.test=true" test
Run Front-End Only Tests with : npm run test
 

Knows Issues / Limitations :

Not all Back-End Tests Execute : Out off 62 Tests, 12 Have Error and 4 Fail

User Accounts Get Created in Locked-Out State
Front-End Tests Have not Been Properly Integrated Yet, They need to be Run Independently
Topology UI is Generated with Mock Data
Topology UI Issues with Layout & Resizing
Input Validations are Un-Reviewed and Limited in validation Scope
